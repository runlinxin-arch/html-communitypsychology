## 放映操作

- 双击 精神健康系统-阅读汇报.html 打开；F 全屏。
- ← / → / 空格 / PageUp / PageDown 翻页；Home/End 首末页。
- N 讲稿抽屉；A 静场；P 打印。
- P2 点击任意标签看 3–4 行摘要；Esc/×/空白关闭。
- 第 9 页两条数据条进入页面时从 0 增长到 76% / 7%；PDF 为静态终态。
