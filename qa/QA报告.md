## 0. 本轮修改

1. **P1 署名行下移**：`.title-credits` 的 `margin-top` 由 44px 改为 72px，署名整体下移，仍保持单行居中。
2. **P2 摘要卡紧贴标签**：优先放在被点标签右侧 12px；右侧放不下时放左侧 12px；垂直居中，并保证卡片上边 ≥150、下边 ≤680；卡片不遮被点标签。

### 4.2 已知限制

- **A13 Windows**：本机无 Windows，仅做字体回退代理；真实 Windows 需换机打开确认。
- **N11 800×600 可读性**：整页等比缩放后 P2 字号偏小；按 A11“完整可见、不溢出”执行，N11 的“可读”不承诺（G9）。

- **PDF Type 3 字体警告**：pdftoppm 提示 Type 3 glyph bounding box 警告；页面像素与文字抽取均正常，不影响页数与内容。
- **数值动效范围**：页码、P1 日期、P2 标签年份、P11 引文年份保持静态；如需这些也计数，可再开一轮小改。
